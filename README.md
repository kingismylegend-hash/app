# Folio
View and edit PDF, Word, PowerPoint, Excel and text files on Android.

1. Put all these files in a GitHub repository (keep the folder layout).
2. Open the repository's Actions tab. The "Build APK" run starts by itself (or press Run workflow).
3. When it finishes (about 5 minutes), open the run and download "folio-apk" from Artifacts.
4. Unzip it, copy app-debug.apk to your phone, tap it, and allow "install unknown apps" if asked.
